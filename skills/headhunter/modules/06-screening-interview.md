## Skill 6: 候选人初筛与深度访谈

### Purpose

通过结构化问题判断候选人的能力、动机、匹配度、风险点和推荐价值。

### Process

1. 基础信息确认：公司、岗位、汇报对象、团队规模、负责范围、当前薪酬、期望薪酬、离职周期、地域意愿。
2. 能力评估：专业能力、管理能力、业务结果、项目经历、跨部门协作、战略能力、解决问题能力。
3. 动机评估：离职原因、职业目标、核心诉求、公司阶段偏好、薪酬/职级/团队/地点优先级。
4. 风险评估：稳定性、薪资匹配、家庭因素、竞业限制、反 Offer、多 Offer、入职时间。

### Output Format

```markdown
## 候选人访谈提纲
### 1. 基础信息
- 目前公司和岗位？
- 当前汇报对象是谁？
- 团队规模多大？
- 主要负责哪些业务？
- 当前薪酬结构？
- 期望薪酬？
- 最早到岗时间？
### 2. 核心经历
- 你过去最核心的项目/业务成果是什么？
- 你在其中承担什么角色？
- 结果如何量化？
- 最大挑战是什么？
- 你如何解决？
### 3. 管理能力
- 目前管理多少人？
- 团队结构如何？
- 如何招聘、培养和淘汰团队成员？
- 遇到低绩效员工如何处理？
### 4. 动机判断
- 为什么考虑新机会？
- 当前平台最不满足你的地方是什么？
- 下一份工作最看重什么？
- 什么情况下你会接受 Offer？
- 什么情况下你不会考虑？
### 5. 风险判断
- 是否有竞业限制？
- 家庭是否支持变动？
- 是否还有其他面试流程？
- 当前公司是否可能反 Offer？
- 离职周期是否可控？
```

## Skills 9-18: 流程推进、Offer、客户与项目管理

### Skill 9: 面试流程推进

用于安排面试、催反馈、跟进候选人、协调客户流程。输出当前阶段、候选人状态、客户状态、下一步动作、候选人侧话术、客户侧话术、风险判断和建议动作。

### Skill 10: Offer 谈判与 Closing

用于终面、谈薪、Offer、离职或入职阶段。确认当前薪酬、期望薪酬、最低接受条件、目标职级、入职时间、家庭意见、多 Offer、反 Offer 可能，并输出客户 Offer 建议、谈判策略、候选人 closing 话术和反 Offer 预案。

### Skill 11: 反 Offer 管理

识别候选人被原公司挽留风险。风险信号包括反复确认薪酬、顾虑增加、离职时间模糊、不愿透露公司反应、老板想再聊聊、家里还要商量、沟通频率下降。输出风险等级、风险信号、真实顾虑、应对策略和建议话术。

### Skill 12: 薪酬分析与谈薪建议

拆解 base、bonus、commission、allowance、stock/option、sign-on、benefits、年终奖、长期激励；判断当前薪酬 vs 客户预算、期望 vs 市场、涨幅合理性、固定与浮动比例、税前税后差异；输出谈薪建议。

### Skill 13: 客户沟通与招聘策略建议

用于客户项目汇报、市场反馈、招聘难点和策略调整。汇总已触达、有效沟通、感兴趣、推荐、面试、拒绝原因；分析薪酬、title、地点、品牌、职责、业务稳定性等反馈；建议调整薪酬、放宽行业/年限、优化 title、缩短流程、加强卖点包装。

### Skill 14: BD 与客户开发

用于开发客户、写 BD 邮件、准备客户会议、设计猎头服务方案。识别高增长、融资后、新业务线、组织扩张、高管变动、招聘密集公司；生成冷启动邮件、LinkedIn、微信、电话、会后跟进；提供普通委托、独家、Retainer、Mapping、RPO、高管寻访建议。

### Skill 15: 职位卖点包装

提炼公司卖点、岗位卖点和候选人相关卖点，包括行业空间、融资、产品、增长、团队、市场地位、全球化、职责影响力、汇报对象、团队规模、权限、晋升、资源、薪酬激励。

### Skill 16: 候选人职业咨询

帮助候选人分析当前平台优势和限制、职业瓶颈、技能积累、市场竞争力、新机会空间、岗位价值、成长性、风险与长期目标匹配度。

### Skill 17: 入职跟进与保证期管理

用于 Offer 接受后、入职前、刚入职或试用期内。跟进离职、背调、入职材料、候选人热度、入职提醒、团队信息、第 1 周、第 1 个月、试用期中期和结束前回访。

### Skill 18: 猎头项目复盘

复盘触达、沟通、推荐、面试、Offer、入职数据；识别客户需求、寻访方向、候选人转化、面试流程、薪酬、Offer 竞争力问题；输出优化建议。
